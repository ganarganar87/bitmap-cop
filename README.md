# BITMAP COP 2.0

Sube `index.html` y `.nojekyll` a la raíz del repositorio GitHub Pages.

Controles: WASD o flechas mover; T o botón transformar; clic o espacio disparar; R recargar misión.

EXPLORAR consulta TXID reales de Bitcoin. DEMO SIN RED genera datos sintéticos marcados claramente y sirve para comprobar controles sin depender de APIs.

La geometría es una interpretación experimental derivada de TXID, no geometría Bitmap oficial. Gateway está previsto como adaptador futuro.
